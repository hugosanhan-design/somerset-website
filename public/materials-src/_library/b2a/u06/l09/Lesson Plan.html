FCE I · Friday B2 (the class before the Unit 6 test, l10)
Aims. By the end of the lesson, students can recognise the specific mistakes that came up in their own class's Unit 6 report, correct them, and apply the same correction to a new sentence of their own.
Format. Group error analysis on the board → corrective slides (real, anonymised examples) → Somerset Arcade round on the same errors → individual take-home fix-it sheet.
Non-negotiable: every example is anonymised. Errors are framed as "things several of you did" or "a common B2 mistake," never attributed to a named student in front of the group.
Before this class (not on the day): mark the scripts collected at the end of l07 (the social-club report). Method: Claude/memory/feedback_writing_error_review_workflow.md (Hugo's rule, with the operational spec: timings, prep, files). Four parts, all compulsory: group error analysis → corrective slides from the real errors → Arcade round on the same errors → one take-home sheet per student with only that student's errors (Fix-It Sheet – <First name>.pdf, saved in the group's dated folder). The generic Fix-It Sheet in this folder is a fallback only. Errors are shown in red bold, never crossed out. A grammar point the group hasn't been taught yet is not drilled: the sheet says which unit and week it comes up in.

The six corrective categories (fill from the real scripts)

  1. Register — factual, neutral report style (not lively/colourful language, no first-person opinion outside the conclusion). A real, local example: a report on a Valencia social club or hobby group should read "the vast majority of members attend weekly" rather than a first-person opinion.
  2. Reporting statistics accurately (the vast majority / well over half / one in ten, matched correctly to the real input-data numbers).
  3. -ing/infinitive or question-tag/indirect-question mix-ups (this unit's two grammar points).
  4. Task coverage (both reasons for leaving AND suggested improvements covered, with a clear recommendation).
  5. Word count (target 140-190 words).
  6. Spelling and basic accuracy.

Fast finisher

Fast finishers write one more sentence for each category using their own fix, before their Arcade turn.

If short of time, cut:

Compress the fix-it sheet to homework rather than class time (Block 4) if the corrective-slide discussion (Block 2) runs long — but always leave time to physically hand out the sheet and explain it. Never cut Block 2 itself.

Exam Tip · identifying the purpose of a text

Guess before you read

  • •Decide what TYPE of text each one is (story, news article, advert, blog, essay).
  • •Think about who wrote it and who the target audience is.
  • •A text can do several things, but it has only ONE main purpose — the reason the writer decided to write it.

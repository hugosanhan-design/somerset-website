1. Frame the lesson · 5 min

Tell the group plainly: today looks at real mistakes from their own Unit 1 writing, the same mistakes that would lose marks in the actual B2 First exam. No names, no ranking. The goal is that everyone leaves able to write the sentence correctly next time, not just to know it was wrong once.

2. Group error analysis, live · 5 min

Before opening the slide deck, write 2–3 of the real sentences on the board (anonymised, exactly as prepared for the deck) and ask the group, as a three/team, to find and fix the mistake themselves first. This makes the deck's explanation land harder, since they've already tried and (probably) partly failed.

3. Corrective slides · 25 min

Materials: Answers_VISTA.html, filled in with this class's real errors before the lesson.

Default category set built into the template (edit, add or remove to match what actually shows up in the scripts):

  1. Register slip — formal language creeping into the informal email (e.g. "I would like to inform you" instead of "just so you know").
  2. Present perfect vs past simple — this unit's grammar point (l05), the single most likely carry-over error into the writing.
  3. Phrasal verb misuse — wrong particle or wrong verb from l06's set (chill out, fall out, cheer up, etc.).
  4. Not answering every question — content/organisation, not language: did the reply actually address what Kelly asked?
  5. Word count — too short (under 140) or too long (over 190), and what that costs on Content.
  6. Spelling / basic accuracy — whatever recurs (contractions written wrong, etc.).

For each category on the slide: the real sentence as written (anonymised), why it's wrong, the corrected version, and a one-line rule the student can reuse.

4. Somerset Arcade: Point Grab · 8 min

Materials: laptop + projector, somerset-arcade/index.html, unit b2a-u01-l09.

Built from the same error categories in template form (register, present perfect, phrasal verbs, word count, common confusions) so it works before the real scripts are read, and stays useful afterward as a quick, active recap of the same points just covered on the slides.

5. Individual fix-it sheet · 15 min

Materials: Fix-It Sheet.html / .pdf, one per student; each student's own marked l07 script.

Each student works through the sheet against their own script: for each category, find an example if they made that mistake (or write "n/a"), write the correction themselves, then write one new sentence of their own using the corrected pattern. This is the individually personalised, take-home half of the lesson — give students the rest of class plus a few days if they need to finish it at home.

6. Return scripts + close · 2 min

Return the marked l07 scripts now. Students should read the teacher's comments with the categories from today already fresh, rather than cold, at some earlier point in the lesson.

If short of time, cut:

Compress the fix-it sheet to homework rather than class time (Block 5) if the corrective-slide discussion (Block 3) runs long — but always leave time to physically hand out the sheet and explain it, so it doesn't get lost. Never cut Block 3 itself; it's the actual point of the lesson.

1. Frame the lesson · 5 min

Tell the group plainly: today looks at real mistakes from their own Unit 2 opinion essay ("Do you think it's better to study abroad?"), the same mistakes that would lose marks in the actual B2 First exam. No names, no ranking. The goal is that everyone leaves able to write the sentence correctly next time, not just to know it was wrong once.

2. Group error analysis, live · 5 min

Before opening the slide deck, write 2–3 of the real sentences on the board (anonymised, exactly as prepared for the deck) and ask the group, as a three/team, to find and fix the mistake themselves first.

3. Corrective slides · 25 min

Materials: Answers_VISTA.html, filled in with this class's real errors before the lesson.

Default category set built into the template (edit, add or remove to match what actually shows up in the scripts — these six are tailored to Unit 2's own content, not simply copied from Unit 1's):

  1. Register: too informal for an opinion essay — the opposite risk from Unit 1's email task. Contractions, text-speak or casual fillers ("like", "stuff") creeping into what should be a fairly formal, exam-style essay.
  2. Valencia link — a strong local third idea some students already know first-hand: exchange or Erasmus schemes run by local universities such as the Universitat de València, useful if a paragraph needs a genuine, well-developed example beyond the two given viewpoints.
  3. Used to / would / past simple mix-ups — this unit's grammar point (l03, l05), the single most likely carry-over error into the essay (e.g. using "would" with a stative verb, or "used to" for a single event).
  4. Missing or wrong linking words — this unit's writing-page language (l07): no topic sentences, or the wrong connector for introducing/adding/concluding a point.
  5. Not covering all three notes points — content/organisation: did the essay actually address studying in another language, experiencing another culture, AND a genuine third idea?
  6. Word count — too short (under 140) or too long (over 190), and what that costs on Content.
  7. Spelling / basic accuracy — whatever recurs (British spelling, contractions written wrong, etc.).

For each category on the slide: the real sentence as written (anonymised), why it's wrong, the corrected version, and a one-line rule the student can reuse.

4. Somerset Arcade: Point Grab · 8 min

Materials: laptop + projector, somerset-arcade/index.html, unit b2a-u02-l09.

Built from the same error categories in template form (essay register, used to/would, linking words, notes coverage, word count) so it works before the real scripts are read, and stays useful afterward as a quick, active recap of the same points just covered on the slides.

5. Individual fix-it sheet · 15 min

Materials: Fix-It Sheet.html / .pdf, one per student; each student's own marked l07 script.

Each student works through the sheet against their own script: for each category, find an example if they made that mistake (or write "n/a"), write the correction themselves, then write one new sentence of their own using the corrected pattern.

6. Return scripts + close · 2 min

Return the marked l07 scripts now. Students should read the teacher's comments with the categories from today already fresh, rather than cold.

If short of time, cut:

Compress the fix-it sheet to homework rather than class time (Block 5) if the corrective-slide discussion (Block 3) runs long — but always leave time to physically hand out the sheet and explain it. Never cut Block 3 itself.

Grammar Ex.1 · complete the rule

Used to or would?

  • aWe can use used to to describe states OR repeated actions in the past.
  • bWe can use would to describe repeated actions in the past, but NOT states.
The test: can you picture it happening more than once as an event? "Would" works. Is it a fact/state ("used to own", "used to be")? Only "used to" works.
Grammar Ex.2 · can it be would?

Tick the ones that work with would

  • 1My dad used to prepare breakfast every Sunday → yes, would
  • 2Sara used to eat a lot of rice in Japan → yes, would
  • 3Did you use to like cabbage? → no (question form)
  • 4I didn't use to own a microwave → no (a state)
  • 5We used to have barbecues every weekend → yes, would
  • 6These chocolates used to cost much less → no (a state/price)
  • 7Did Klaus use to be a chef? → no ("be" is a state)
  • 8My sister used to throw her food on the floor → yes, would
Items 1, 2, 5, 8 tick: they're all repeated actions. The rest are states, questions or facts — would can't replace used to there.
Grammar Ex.3 · be/get used to

Already familiar, or becoming familiar?

  • 1"I'm used to the late nights" (worked there 6 years) → a, already usual/familiar
  • 2"I'm getting used to the late nights" (started 2 weeks ago) → b, becoming familiar
be used to = already familiar (a state). get used to = in the process of becoming familiar (a change). Both take -ing or a noun, never a bare infinitive.
Grammar Ex.4 · choose a, b or c

Mix of all three forms

  • 1I am used to (a) eating fruit and yoghurt.
  • 2My cookery teacher used to (c) be a chef.
  • 3Were you used to (c) preparing food at home?
  • 4Eloise couldn't get used to (b) the spicy food.
  • 5Sonia and Masha are getting used to (a) the lunches.
  • 6Is Haru getting used to (c) his new eating plan?
  • 7I used to (c) eat a lot of meat before becoming vegetarian.
  • 8Did you get used to (a) helping prepare dinner?
Read the whole sentence for a time clue: "for years" = already familiar; "loved it, but" (a past habit that stopped) = used to; "started... two weeks ago" = getting used to.

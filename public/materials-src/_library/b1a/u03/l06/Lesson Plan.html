1–4. Writing error-review · 40 min

Materials: marked l05 scripts, board, Answers_VISTA.html, Somerset Arcade, Fix-It Sheets.

Teacher prep, done between l05 and this class: mark every script (four-criteria B1 Preliminary writing rubric: content, communicative achievement, organisation, language). List each student's errors, tag each with a category and whether the grammar involved has already been taught this year (check the group's unit map before flagging anything as "not yet taught" — present perfect was taught this same unit, l02, so it should already be fresh). Choose 4–6 categories that 2+ students actually made, with one real, anonymised example each ("a student wrote…", never a name). Fill Answers_VISTA.html's placeholders with those real examples, rebuild the Arcade file from the same errors, and build one Fix-It Sheet PDF per student (3–6 items each, their own errors only) — save all of it in that date's materials folder.

Likely category candidates for this unit's writing (l05's environment email, pp.38-39) — confirm against the real scripts rather than assuming: formal language creeping into an informal email (missing contractions, no greeting/sign-off); paragraph structure (all content in one block instead of greeting/news/detail/closing); present perfect misuse (using the past simple for an unfinished period, e.g. "I recycled since September" instead of "I've recycled since September" — this unit's own grammar point); spelling of environment vocabulary (environment, pollution, renewable); word count (well under or over the 100–130-word target).

6. Unit 3 Test · 40 min

Materials: Unit 3 Test.html/.pdf (student copy), Unit 3 Test_TEACHER.html/.pdf (key, do not photocopy), Unit 3 Test Listening.mp3.

Adapted from the official New Close-up B1 End-of-Unit Test 3 (Cengage/National Geographic Learning, permission granted to photocopy for classroom use). Reading (Exam Task, arctic wolf spiders and climate change), Vocabulary (geographical features + fossil fuel/environment word bank + prepositions), Grammar (present perfect simple/continuous + articles), Listening (climate change in Norway). The writing section (20 marks in the official test) is not included — Unit 3's writing (SB pp.38-39, the environment email) was already written in class and marked separately. Two full exercises were also dropped to fit the 90-minute session alongside the error-review (see BUILD_REPORT.md): the fossil-fuel word-bank vocabulary exercise and the error-correction grammar exercise, both already well covered by l02 and l04's practice. One sentence is localised to a real Valencia setting; the tested grammar and correct answers are unchanged from the original.

Total: 44 marks, 40 minutes. Reading /5 · Vocabulary /16 · Grammar /17 · Listening /6. Full key in Unit 3 Test_TEACHER.html/.pdf.

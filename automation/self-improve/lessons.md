# Lessons

## 2026-10-03 — Somerset banner visual direction

- What went wrong: Earlier banner variants drifted toward game art and then toward generic watercolour.
- Do instead: Use the user-selected screenshot as the canonical visual reference: detailed, slightly uneven wooden coloured-pencil strokes on warm paper, with recognisable Somerset landmarks. Register seasonal edits to one master composition so animation overlays stay aligned.
- Trigger: Requests to change, animate, or extend the Somerset website landscape.
